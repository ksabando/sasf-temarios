# Proyecto Final - Simulación de Entrevista Técnica

## Introducción
Este módulo integra todos los conceptos del curso en un proyecto simulado que replica un entorno real de desarrollo. Prepara para entrevistas técnicas sobre Git.

## Escenarios del Proyecto

### Desarrollo
Feature branches, code review, merges a develop, conflictos.

### QA
Gestión de releases, bugfix branches, tags de versión.

### DevOps
CI/CD pipelines, hooks, automatización de despliegues.

### Open Source
Fork, PRs, rebase interactivo, squash antes de merge.

### Enterprise
Submodules, LFS, firmas GPG, hooks del lado del servidor.

## 10 Ejercicios Prácticos

1. **Init y configuración**: Inicializar repo con .gitignore y .gitattributes
2. **Git Flow**: Feature branches con merge a develop
3. **Conflicto complejo**: Resolver conflicto entre dos ramas
4. **Interactive rebase**: Squash 5 commits en 2 con mensajes convencionales
5. **Partial stash**: Stash parcial y recuperación en otra rama
6. **Cherry-pick**: Hotfix de main a release branch
7. **Pre-commit hook**: Hook que ejecuta linter automáticamente
8. **CI/CD pipeline**: GitHub Actions (build + test + tag)
9. **Firmas GPG**: Commits firmados y verificación
10. **LFS**: Migrar archivos grandes y limpiar historial

## 60 Preguntas de Entrevista (6 categorías, 10 cada una)

| Categoría | Temas |
|-----------|-------|
| Fundamentos | init, add, commit, status, log, diff |

| Buenas Prácticas | conventional commits, gitignore, gitattributes, flujos |
