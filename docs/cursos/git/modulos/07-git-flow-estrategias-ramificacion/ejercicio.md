# Ejercicios - Módulo 07

## Ejercicio 1: Implementar Git Flow manualmente
Crea un repositorio e implementa Git Flow manualmente: crea `develop`, una `feature/login`, fusiónala a `develop`, crea una `release/v1.0`, y fusiónala a `main` con tag.

## Ejercicio 2: GitHub Flow con PR simulado
Simula GitHub Flow: desde `main` crea `feature/homepage`, haz commits, abre un PR (usando `gh` o simulado con merge local), haz code review y fusiona.

## Ejercicio 3: Crear una rama hotfix
Desde `main` (con commits previos), crea una rama `hotfix/critical-bug`, corrige, fusiona a `main` y también a `develop`.

## Ejercicio 4: Comparar estrategias en tabla
Crea un archivo `comparativa.md` con una tabla comparativa de Git Flow, GitHub Flow, GitLab Flow y Trunk-Based Development (ramas, pros, contras, casos de uso).

## Ejercicio 5: Convención de nomenclatura
Dados 5 escenarios (nueva feature, bug, hotfix urgente, release, experimento), propón el nombre de rama adecuado según Git Flow.
