# Ejercicios - Módulo 09

## Ejercicio 1: Fork y PR
Haz fork de un repositorio público (o simulado), clónalo, crea una rama, haz cambios, sube, abre un PR y asígnale un reviewer.

## Ejercicio 2: Revisar un PR con comentarios
En un PR existente (o simulado localmente), añade comentarios en líneas específicas, solicita cambios y finalmente aprueba.

## Ejercicio 3: gh CLI para crear PR
Usa `gh pr create` para crear un PR desde la terminal con título y descripción. Luego lista los PRs abiertos con `gh pr list`.

## Ejercicio 4: Squash merge vs rebase merge
Crea una rama con 3 commits. Fúndela primero con squash merge y observa el historial. Luego repite con rebase merge. Compara `git log`.

## Ejercicio 5: Configurar branch protection
En GitHub, configura una regla de branch protection para `main` que requiera: 1 approval, checks pasados, PR actualizado.
