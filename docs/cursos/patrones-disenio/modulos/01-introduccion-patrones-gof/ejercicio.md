## Ejercicio 3: Clasificación de Patrones

Clasifica cada patrón en Creacional, Estructural o Comportamiento y explica por qué:

1. **Adapter** — Convierte interfaz de una clase en otra que el cliente espera
2. **Observer** — Notifica cambios a múltiples objetos dependientes
3. **Builder** — Construye objetos complejos paso a paso
4. **Proxy** — Controla acceso a otro objeto
5. **Command** — Encapsula peticiones como objetos
6. **Singleton** — Garantiza una única instancia
7. **Composite** — Trata objetos individuales y compuestos uniformemente

## Ejercicio 4: Identificar Patrones en Spring Boot

Explora la documentación de Spring Boot y responde qué patrón representa cada componente. Justifica:

1. `JdbcTemplate` — ejecuta consultas SQL
2. `@Autowired` — inyección de dependencias
3. `@EventListener` — manejo de eventos
4. `SecurityFilterChain` — cadena de filtros de seguridad
5. `PlatformTransactionManager` — manejo de transacciones
