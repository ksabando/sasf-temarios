## Modulo 01 - Fundamentos ETL y SSIS

- Conceptos de extraccion, transformacion y carga.
- Casos de uso empresariales: migraciones, sincronizacion y reporting.
- Estructura de un paquete SSIS.
- Connection managers, control flow y data flow.
- Laboratorio: importar CSV a SQL Server.

---

## Modulo 02 - Transformaciones y Calidad de Datos

- Limpieza y normalizacion de datos.
- Derived columns, lookups y conditional split.
- Manejo de errores en flujos.
- Auditoria de cargas.
- Laboratorio: ETL con reglas de validacion.

---

## Modulo 03 - VB.NET para Mantenimiento

- Sintaxis VB.NET comparada con C#.
- Clases, propiedades, metodos y eventos.
- Manejo de excepciones.
- Lectura de codigo legacy.
- Laboratorio: traducir fragmentos VB.NET a C#.

---

## Modulo 04 - Web Forms y Proyecto Legacy

- Ciclo de vida de Web Forms.
- Page, ViewState, PostBack y controles servidor.
- Diferencias con MVC.
- Estrategias de mantenimiento y migracion incremental.
- Proyecto final: paquete ETL + analisis de modulo legacy.

---

## Modulo 05 - SSIS Avanzado y Parametrizacion

- Variables y parametros.
- Configuracion por ambiente.
- Ejecucion con SQL Server Agent.
- Logging de paquetes.
- Laboratorio: paquete parametrizable y agendado.

---

## Modulo 06 - Migracion y Sincronizacion de Datos

- Cargas incrementales.
- Deteccion de cambios.
- Upserts.
- Control de duplicados.
- Laboratorio: sincronizar origen legacy con base nueva.

---

## Modulo 07 - Modernizacion Legacy

- Strangler Fig aplicado a sistemas .NET legacy.
- Identificacion de modulos candidatos.
- Wrappers, APIs fachada y convivencia.
- Riesgos de reescritura total.
- Laboratorio: plan de modernizacion incremental.

---

## Modulo 08 - Proyecto Integrador Fase 5

- ETL con auditoria.
- Analisis VB.NET/Web Forms.
- Plan de mantenimiento.
- Propuesta de migracion incremental.
- Proyecto final: integracion de datos y diagnostico legacy.

---

## Objetivo del Curso

Comprension funcional para mantener sistemas existentes, no dominio profundo de tecnologias legacy.
