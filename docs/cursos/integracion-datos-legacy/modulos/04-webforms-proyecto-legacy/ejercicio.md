## Proyecto Final: ETL + Analisis Legacy

Entrega:

1. Paquete ETL funcional con staging, validacion y carga final.
2. Informe de un modulo VB.NET/Web Forms.
3. Diagrama simple del flujo actual.
4. Lista de riesgos tecnicos.
5. Plan de mantenimiento o migracion incremental.

## Criterios

- Enfoque funcional, no reescritura total.
- Evidencia de ejecucion del ETL.
- Recomendaciones realistas.
