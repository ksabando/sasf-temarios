## Modernizacion Legacy

Modernizar no siempre significa reescribir. Una estrategia incremental reduce riesgo y permite extraer capacidades gradualmente.

| Estrategia | Descripcion |
|------------|-------------|
| Strangler Fig | Reemplazo gradual por bordes |
| API fachada | Encapsular legacy detras de contrato nuevo |
| Wrapper | Adaptar codigo viejo sin modificarlo mucho |
| Dual run | Ejecutar viejo y nuevo para comparar |

## Resumen

La prioridad es mantener continuidad operativa mientras se reduce deuda.
