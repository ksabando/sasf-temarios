## ETL y SSIS

ETL significa extraer, transformar y cargar datos. SSIS permite construir paquetes para mover datos entre archivos, bases de datos y otros origenes.

### Componentes SSIS

| Componente | Rol |
|------------|-----|
| Connection Manager | Define conexion a origen o destino |
| Control Flow | Orquesta tareas |
| Data Flow | Mueve y transforma filas |
| Task | Unidad de trabajo |

## Recomendacion

Registrar cantidad de filas leidas, procesadas y rechazadas desde el primer paquete.
