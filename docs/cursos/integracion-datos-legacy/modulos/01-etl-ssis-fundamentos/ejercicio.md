## Ejercicio: CSV a SQL Server

Crea un paquete SSIS que:

1. Lea un archivo CSV de productos.
2. Cargue datos en una tabla staging.
3. Inserte datos validos en tabla final.
4. Registre cantidad de filas procesadas.

## Criterios

- Separar staging de tabla final.
- Documentar origen y destino.
- Validar ejecucion repetible.
