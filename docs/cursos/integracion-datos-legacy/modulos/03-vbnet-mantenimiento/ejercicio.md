## Ejercicio: Traducir VB.NET a C#

Toma un fragmento VB.NET con:

1. Una clase.
2. Un metodo con `If`.
3. Manejo de excepciones.
4. Un evento o handler.

Traducelo a C# y explica diferencias.

## Criterios

- Mantener comportamiento equivalente.
- Identificar nombres y tipos.
- Documentar riesgos de traduccion.
