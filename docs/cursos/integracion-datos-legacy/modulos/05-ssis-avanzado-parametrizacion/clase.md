## SSIS Avanzado y Parametrizacion

Los paquetes productivos deben ejecutarse en diferentes ambientes, registrar su ejecucion y poder agendarse.

| Recurso | Uso |
|---------|-----|
| Variables | Valores internos del paquete |
| Parametros | Valores configurables desde fuera |
| Logging | Auditoria y diagnostico |
| SQL Server Agent | Ejecucion programada |

## Resumen

Un paquete sin parametros ni logs es dificil de operar en produccion.
