## Proyecto Integrador Fase 5

El cierre combina integracion de datos y comprension legacy: un ETL operable, analisis funcional de un modulo antiguo y una propuesta de modernizacion incremental.

### Entregables

| Entregable | Evidencia |
|------------|-----------|
| ETL | Ejecucion y logs |
| Calidad de datos | Rechazos auditados |
| Analisis legacy | Flujo y dependencias |
| Plan | Pasos, riesgos y rollback |

## Resumen

El valor del curso es poder intervenir sistemas existentes con bajo riesgo.
