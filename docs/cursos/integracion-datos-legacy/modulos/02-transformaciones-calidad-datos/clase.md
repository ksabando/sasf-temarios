## Transformaciones y Calidad de Datos

Un ETL empresarial no solo mueve datos: tambien limpia, normaliza y rechaza registros invalidos.

### Reglas comunes

| Regla | Ejemplo |
|-------|---------|
| Requerido | Producto debe tener nombre |
| Formato | Fecha valida |
| Rango | Precio mayor a cero |
| Referencia | Categoria existe |

## Recomendacion

No descartar filas sin registrarlas. Todo rechazo debe poder auditarse.
