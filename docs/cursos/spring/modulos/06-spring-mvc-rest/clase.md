## Resumen

- `@RestController` combina `@Controller` y `@ResponseBody`
- Las anotaciones `@GetMapping`, `@PostMapping`, etc. simplifican el mapeo de rutas
- `ResponseEntity` permite control total sobre la respuesta HTTP
- Content Negotiation permite servir JSON y XML según el cliente
- Los principios REST guían el diseño de URIs y operaciones
- La API de Task sigue el patrón RESTful con CRUD completo
