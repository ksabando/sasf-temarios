## Resumen

- `springdoc-openapi` expone automáticamente Swagger UI en `/swagger-ui.html`
- `@Operation` documenta el propósito y comportamiento de cada endpoint
- `@ApiResponse` describe los códigos de respuesta posibles
- `@Schema` enriquece la documentación de los DTOs
- `@Tag` organiza los endpoints en grupos lógicos
- Swagger UI permite probar la API interactivamente
