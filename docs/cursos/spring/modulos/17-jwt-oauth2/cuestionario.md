**1. ¿Cuántas partes tiene un JWT?**
- a) 2
- b) 3
- c) 4
- d) 5

- a) La clave secreta
- b) Los claims (datos del usuario)
- c) El algoritmo de firma

**3. ¿Qué librería se usa comúnmente para JWT en Spring?**
- a) java-jwt
- b) jjwt
- c) spring-jwt
- d) auth0-jwt

**4. ¿Qué filtro intercepta requests para validar el JWT?**

- b) JwtAuthenticationFilter

**5. ¿En qué header se envía el JWT desde el frontend?**

- c) configure()
- d) setPrincipal()

**7. ¿Qué tipo de sesión se usa con JWT?**
- a) ALWAYS
- b) STATELESS
- c) IF_REQUIRED
- d) NEVER

**8. ¿Qué endpoint expone AuthService para obtener el token?**

**9. ¿Qué bean necesita AuthService para validar credenciales?**

- b) AuthenticationManager
