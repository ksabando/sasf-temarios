## Resumen

- `@SpringBootTest` carga el contexto completo para tests de integración
- `@WebMvcTest` + `MockMvc` testea solo la capa web
- `@MockitoBean` simula dependencias del servicio
- JsonPath permite assertions precisas sobre JSON
- JaCoCo mide y reporta la cobertura de tests
- Tests bien escritos garantizan que la API de Task funcione correctamente
