## Resumen

- `@RequestParam`, `@PathVariable`, `@RequestBody` recuperan datos de la petición
- Los DTOs desacoplan la capa de persistencia de la API
- MapStruct genera automáticamente el código de mapeo
- `Pageable`, `Page<T>` y `Sort` proporcionan paginación estándar
- Los filtros combinados con paginación ofrecen una API flexible
