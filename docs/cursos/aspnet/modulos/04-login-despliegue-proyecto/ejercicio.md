## Proyecto Final: MVC conectado a API

Construye una interfaz web que permita:

1. Login contra API.
2. Guardar token para requests protegidos.
3. Listar productos.
4. Crear productos.
5. Mostrar errores de autenticacion.
6. Preparar despliegue basico.

## Criterios

- Login funcional.
- CRUD consume API protegida.
- Configuracion por ambiente.
