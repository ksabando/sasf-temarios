### 1. Diferencia entre partial view y view component?

**Respuesta:** Partial view es un fragmento de vista; view component puede tener logica propia y dependencias.

---

### 2. Por que personalizar paginas de error?

**Respuesta:** Para no exponer detalles internos y dar una experiencia clara al usuario.
