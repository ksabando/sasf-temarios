## UI, Componentizacion y Manejo de Errores

Las vistas crecen rapido. Partial views, layouts y view components ayudan a reutilizar UI y mantener consistencia.

| Recurso | Uso |
|---------|-----|
| Partial view | Fragmento simple de UI |
| View component | UI con logica propia |
| Layout | Estructura compartida |
| Error page | Respuesta controlada ante fallos |

## Resumen

Una interfaz mantenible evita duplicar formularios, alertas y bloques comunes.
