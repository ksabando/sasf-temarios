## Proyecto Integrador ASP.NET

El proyecto final consolida MVC/Razor, consumo de API, autenticacion, manejo de errores, UI reutilizable y preparacion de despliegue.

### Checklist

| Area | Validacion |
|------|------------|
| Auth | Login y logout funcionales |
| API | CRUD consume endpoints protegidos |
| UX | Mensajes claros |
| Config | URLs por ambiente |
| Deploy | Instrucciones documentadas |

## Resumen

El frontend debe demostrar flujo completo de usuario, no solo paginas sueltas.
