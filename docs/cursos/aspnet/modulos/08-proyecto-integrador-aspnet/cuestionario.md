### 1. Que debe demostrar el proyecto final?

**Respuesta:** Que el alumno puede construir una interfaz web que consume una API real de forma segura y mantenible.

---

### 2. Que configuracion no debe hardcodearse?

**Respuesta:** URLs de API, secretos, tokens y configuraciones dependientes del ambiente.
