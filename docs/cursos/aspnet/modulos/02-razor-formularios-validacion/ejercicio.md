## Ejercicio: Formulario de Producto

Crea una pantalla para registrar productos:

1. Nombre requerido.
2. Precio mayor a cero.
3. Stock mayor o igual a cero.
4. Mensajes de error por campo.
5. Redireccion al listado al guardar.

## Criterios

- Usar Data Annotations.
- Validar `ModelState`.
- No guardar si el modelo es invalido.
