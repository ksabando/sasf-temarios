## Ejercicio: Productos desde API

Conecta el MVC con la API de productos:

1. Crear servicio `ProductApiClient`.
2. Listar productos desde `GET /api/products`.
3. Crear productos con `POST /api/products`.
4. Manejar errores HTTP.
5. Mostrar mensaje al usuario.

## Criterios

- Usar typed client.
- No llamar API directamente desde la vista.
- Manejar error 401 y 500.
