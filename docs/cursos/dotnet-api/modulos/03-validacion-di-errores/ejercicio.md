## Ejercicio: API Robusta

Mejora el CRUD:

1. Crear `ProductService`.
2. Registrar servicio en DI.
3. Agregar validaciones de nombre, precio y stock.
4. Crear middleware de errores.
5. Estandarizar respuestas de error.

## Criterios

- Controller delgado.
- Validaciones claras.
- Errores sin stack trace en respuesta.
