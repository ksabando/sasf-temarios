## Testing, Deploy y Proyecto Integrador

Las APIs empresariales requieren pruebas automaticas y configuracion por ambiente. Las pruebas de integracion validan endpoints reales y pipeline HTTP.

| Tipo | Alcance |
|------|---------|
| Unitario | Servicio o regla aislada |
| Integracion | API + DI + base de prueba |
| Smoke | Verificacion rapida post-deploy |

## Resumen

Una API de portafolio debe poder ejecutarse, probarse y configurarse sin cambios de codigo.
