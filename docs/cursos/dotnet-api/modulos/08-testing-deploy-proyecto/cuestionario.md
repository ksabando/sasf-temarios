### 1. Que valida una prueba de integracion en Web API?

**Respuesta:** Que el endpoint funciona pasando por middleware, DI, routing y dependencias configuradas.

---

### 2. Por que separar configuracion por ambiente?

**Respuesta:** Para cambiar URLs, secretos y base de datos sin modificar codigo.
