### 1. Diferencia entre autenticacion y autorizacion?

**Respuesta:** Autenticacion verifica identidad. Autorizacion verifica permisos.

---

### 2. Que debe contener un JWT?

**Respuesta:** Claims necesarias, expiracion y firma. No debe contener secretos sensibles.
