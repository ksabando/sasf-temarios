## Proyecto Final: API CRUD con Login

Construye una API que incluya:

1. Registro de usuario.
2. Login con JWT.
3. CRUD protegido de productos.
4. Swagger con soporte para Bearer token.
5. SQL Server con EF Core.

## Criterios

- Endpoints publicos solo para auth.
- CRUD protegido con `[Authorize]`.
- Documentacion Swagger usable.
