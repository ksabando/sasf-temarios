## REST y Web API

Una API REST expone recursos mediante HTTP. ASP.NET Core permite crear controllers, mapear rutas y devolver respuestas con codigos de estado adecuados.

### Verbos principales

| Verbo | Uso |
|-------|-----|
| GET | Consultar |
| POST | Crear |
| PUT | Reemplazar |
| PATCH | Modificar parcialmente |
| DELETE | Eliminar |

## Recomendacion

Separar entidades internas de DTOs para no exponer el modelo de persistencia directamente.
