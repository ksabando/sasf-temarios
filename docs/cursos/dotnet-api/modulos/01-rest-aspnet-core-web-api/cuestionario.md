### 1. Que diferencia hay entre recurso y endpoint?

**Respuesta:** El recurso es la entidad conceptual expuesta, como productos. El endpoint es la URL y verbo concreto para interactuar con ese recurso.

---

### 2. Por que usar DTOs?

**Respuesta:** Para controlar el contrato externo y evitar exponer detalles internos de entidades o base de datos.
