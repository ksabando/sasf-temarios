## Ejercicio: API de Productos en Memoria

Crea endpoints para:

1. `GET /api/products`
2. `GET /api/products/{id}`
3. `POST /api/products`
4. `PUT /api/products/{id}`
5. `DELETE /api/products/{id}`

## Criterios

- Usar DTOs.
- Devolver `404` cuando no exista el recurso.
- Devolver `201 Created` al crear.
