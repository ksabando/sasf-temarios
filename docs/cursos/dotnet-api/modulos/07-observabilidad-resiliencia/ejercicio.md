## Ejercicio: API Observable

Agrega a la API:

1. Logging estructurado por request.
2. Correlation ID.
3. Health check de base de datos.
4. Manejo de timeouts para dependencias externas simuladas.

## Criterios

- No loguear secretos.
- Exponer `/health`.
- Incluir correlation ID en errores.
