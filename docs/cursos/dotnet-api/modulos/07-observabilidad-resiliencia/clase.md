## Observabilidad y Resiliencia Basica

Una API en produccion debe explicar que ocurre. Logging, health checks y correlation IDs ayudan a diagnosticar errores y latencia.

| Practica | Beneficio |
|----------|-----------|
| Logging estructurado | Busquedas y filtros en logs |
| Correlation ID | Trazar una request completa |
| Health check | Validar disponibilidad |
| Timeout | Evitar esperas infinitas |

## Resumen

No basta con que la API funcione localmente; debe ser operable.
