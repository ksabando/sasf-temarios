### 1. Que es una migration?

**Respuesta:** Un cambio versionado del esquema de base de datos generado desde el modelo de EF Core.

---

### 2. Por que usar `async` con EF Core?

**Respuesta:** Porque las consultas a base de datos son I/O-bound y no deben bloquear threads de servidor.
