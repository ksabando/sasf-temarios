## Ejercicio: CRUD Persistente

Conecta la API a SQL Server:

1. Crear entidad `Product`.
2. Crear `AppDbContext`.
3. Configurar connection string.
4. Crear migration.
5. Actualizar endpoints para usar EF Core.

## Criterios

- Usar metodos asincronos.
- No usar entidades como input directo si hay DTOs.
- Confirmar que la base se crea con migration.
