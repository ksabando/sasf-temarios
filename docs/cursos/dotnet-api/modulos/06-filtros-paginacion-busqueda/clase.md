## Filtros, Paginacion y Busqueda

Las APIs reales no devuelven toda la tabla. Deben permitir filtrar, ordenar y paginar resultados de forma predecible.

### Parametros comunes

| Parametro | Uso |
|-----------|-----|
| `page` | Numero de pagina |
| `pageSize` | Tamano de pagina |
| `search` | Texto de busqueda |
| `sortBy` | Campo de ordenamiento |

## Resumen

Definir limites maximos de pagina protege la base de datos y la API.
