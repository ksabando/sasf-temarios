### Ejercicio 2: Ordenar tareas por fecha descendente

Las tareas deben mostrarse ordenadas de la más reciente a la más antigua (según `createdAt`). Asegúrate de no mutar el estado original.

---

### Ejercicio 3: Input de búsqueda

Agregar un input "Buscar tareas..." que filtre las tareas cuyo título contenga el texto ingresado (case-insensitive, usando `includes`).

---

### Ejercicio 4: Contador

Mostrar debajo del título "Mis Tareas" un texto como: **"3 pendientes de 5 totales"**. El contador debe actualizarse en tiempo real.

---

### Ejercicio 5: Tareas completadas al final

Al ordenar la lista, las tareas no completadas deben aparecer primero y las completadas al final. Combinar este orden con el filtro de búsqueda y el filtro de estado.
