## Ejercicio: Optimizar Consultas

Toma tres consultas lentas y:

1. Revisa el plan de ejecucion.
2. Identifica scans costosos.
3. Propone indices.
4. Reescribe filtros no SARGables.

## Criterios

- Justificar cada indice.
- Comparar antes y despues.
- Evitar optimizaciones especulativas.
