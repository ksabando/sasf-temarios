## Ejercicio: Consultas de Catalogo

Crea tablas `Categorias` y `Productos`, luego escribe consultas para:

1. Listar productos activos.
2. Buscar productos por texto.
3. Ordenar por precio descendente.
4. Mostrar solo productos con stock mayor a cero.

## Criterios

- Usar `WHERE` y `ORDER BY`.
- Evitar `SELECT *`.
- Agregar claves primarias.
