### 1. Que es una clave primaria?

**Respuesta:** Una columna o conjunto de columnas que identifica de forma unica cada fila.

---

### 2. Por que evitar `SELECT *`?

**Respuesta:** Porque trae columnas innecesarias, acopla la consulta al esquema completo y puede afectar rendimiento.
