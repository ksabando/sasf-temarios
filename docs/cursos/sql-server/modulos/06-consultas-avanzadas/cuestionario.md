### 1. Para que sirve `ROW_NUMBER`?

**Respuesta:** Asigna un numero secuencial a filas dentro de un orden definido.

---

### 2. Que aporta una CTE?

**Respuesta:** Permite dividir una consulta compleja en un bloque nombrado y legible.
