## Proyecto Integrador SQL Server

Entrega una base de datos completa con modelo normalizado, datos semilla, vistas, procedimientos, indices, permisos y script de backup/restore.

## Criterios

- Scripts recreables desde cero.
- Permisos por rol.
- Consultas principales optimizadas.
- Documentacion de instalacion.
