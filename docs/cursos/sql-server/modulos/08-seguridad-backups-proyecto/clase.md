## Seguridad, Backups y Proyecto

Una base empresarial debe limitar permisos, permitir recuperacion y poder desplegarse de forma repetible.

| Tema | Practica |
|------|----------|
| Permisos | Menor privilegio |
| Roles | Agrupar accesos |
| Backup | Plan probado |
| Restore | Validacion periodica |

## Resumen

Una base no esta lista si no se puede restaurar ni explicar quien puede acceder a que.
