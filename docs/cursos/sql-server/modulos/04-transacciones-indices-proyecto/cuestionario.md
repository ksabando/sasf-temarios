### 1. Que garantiza una transaccion?

**Respuesta:** Que un conjunto de operaciones se confirme completo o se revierta completo.

---

### 2. Que costo tiene un indice?

**Respuesta:** Mejora lecturas, pero aumenta almacenamiento y costo de escrituras.
