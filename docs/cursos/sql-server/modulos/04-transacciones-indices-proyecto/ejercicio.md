## Proyecto Final: Base de Datos para API

Diseña una base para productos y usuarios con:

1. Tablas normalizadas.
2. Claves primarias y foraneas.
3. Vistas de consulta.
4. Procedimientos basicos.
5. Transaccion para movimiento de stock.

## Criterios

- Scripts ejecutables desde cero.
- Datos semilla.
- Indices en columnas de busqueda frecuente.
