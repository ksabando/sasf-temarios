### 1. Que problema resuelve una tabla puente?

**Respuesta:** Modela relaciones muchos a muchos separando ambas entidades.

---

### 2. Cuando se justifica desnormalizar?

**Respuesta:** Cuando una necesidad real de lectura o performance supera el costo de duplicar datos.
