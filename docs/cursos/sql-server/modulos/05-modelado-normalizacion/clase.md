## Modelado Relacional y Normalizacion

Un buen modelo relacional evita duplicacion innecesaria y protege la consistencia. La normalizacion ayuda a separar entidades, relaciones y dependencias.

| Forma | Objetivo |
|-------|----------|
| 1FN | Valores atomicos |
| 2FN | Dependencia completa de la clave |
| 3FN | Sin dependencias transitivas |

## Resumen

Normalizar mejora integridad; desnormalizar solo cuando existe una necesidad concreta de lectura o performance.
