## Ejercicio: Reportes de Inventario

Crea:

1. Una vista de productos con categoria.
2. Un reporte de stock por categoria.
3. Un procedimiento para buscar productos por texto.
4. Un procedimiento para actualizar stock.

## Criterios

- Usar parametros.
- Usar `GROUP BY`.
- Separar lectura y actualizacion.
