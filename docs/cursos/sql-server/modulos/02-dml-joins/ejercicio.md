## Ejercicio: Productos y Categorias

Construye scripts para:

1. Insertar categorias.
2. Insertar productos asociados.
3. Actualizar precios.
4. Consultar productos con su categoria.
5. Detectar categorias sin productos.

## Criterios

- Usar claves foraneas.
- Usar `INNER JOIN` y `LEFT JOIN`.
- No borrar datos sin `WHERE`.
