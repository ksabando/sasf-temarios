﻿# Ejercicios -” Registros de Imagenes

## Ejercicio 1: Login y Push
Haz login en Docker Hub. Crea un tag y haz push de una imagen.

## Ejercicio 2: Registry local
Levanta un registry local en puerto 5000. Haz push de una imagen.

## Ejercicio 3: Pull desde registry local
Elimina la imagen local. Haz pull desde el registry local.

## Ejercicio 4: GitHub Container Registry
Haz login en ghcr.io con token. Haz push de una imagen.

## Ejercicio 5: Multi-arquitectura
Usa docker buildx para crear una imagen multi-arquitectura.
