﻿# Ejercicios -” Servicios, Stacks y Secrets en Swarm

## Ejercicio 1: Servicio replicado
Crea un servicio web con 3 replicas de nginx.

## Ejercicio 2: Escalar
Escala el servicio a 5 replicas. Verifica con docker service ps web.

## Ejercicio 3: Rolling update
Actualiza la imagen del servicio con --update-delay 10s.

## Ejercicio 4: Stack deploy
Crea un docker-compose.yml con deploy config. Despliega con docker stack deploy.

## Ejercicio 5: Secrets
Crea un secret y asignalo a un servicio. Verifica dentro del contenedor.
