﻿# Ejercicios -” Introduccion a Kubernetes

## Ejercicio 1: Cluster local
Levanta Kubernetes en Docker Desktop o instala kind. Verifica con kubectl cluster-info.

## Ejercicio 2: Primer Deployment
Crea un Deployment de nginx con 3 replicas usando kubectl create deployment.

## Ejercicio 3: Exponer servicio
Expone el deployment con kubectl expose deployment.

## Ejercicio 4: Escalar
Escala el deployment a 5 replicas. Verifica con kubectl get pods.

## Ejercicio 5: Rolling update
Actualiza la imagen del deployment a nginx:1.25-alpine. Observa el rolling update.
