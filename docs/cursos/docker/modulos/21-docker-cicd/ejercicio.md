﻿# Ejercicios -” Docker en CI/CD

## Ejercicio 1: GitHub Actions basico
Crea un workflow que construya una imagen Docker en cada push a main.

Agrega login y push a Docker Hub desde CI.

## Ejercicio 3: Cache

## Ejercicio 4: Multi-platform
Build para amd64 y arm64 simultaneamente.

## Ejercicio 5: Testcontainers (opcional)
Escribe un test de integracion que use Testcontainers para PostgreSQL.
