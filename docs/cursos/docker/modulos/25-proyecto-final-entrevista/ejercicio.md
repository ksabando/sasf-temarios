﻿# Ejercicios -” Proyecto Final + Simulacion de Entrevista

## Ejercicio 1: Dockerfiles multi-stage
Crea Dockerfiles optimos para cada microservicio.

## Ejercicio 2: Docker Compose completo
Crea docker-compose.yml con frontend, gateway, 3 microservicios, 2 BD, Kafka, monitoreo.

## Ejercicio 3: Healthchecks
Agrega healthchecks a todos los servicios. Usa condition: service_healthy.

## Ejercicio 4: CI/CD Pipeline
Crea GitHub Actions workflow: build, test, scan, push, deploy.

## Ejercicio 5: Kubernetes
Crea Deployment + Service + Ingress para un microservicio.

## Ejercicio 6: Helm Chart
Crea un Chart para desplegar un microservicio con values configurables.

## Ejercicio 7: Seguridad
Ejecuta Docker Bench Security. Puntaje minimo 90%.

## Ejercicio 8: Logs centralizados
Configura Loki + Promtail + Grafana para logs.

## Ejercicio 9: Monitoreo
Configura cAdvisor + Prometheus + Grafana.

## Ejercicio 10: Backup
Script de backup y restore de todos los volumenes de datos.
