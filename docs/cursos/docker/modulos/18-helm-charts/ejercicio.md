﻿# Ejercicios -” Helm Charts

## Ejercicio 1: Crear Chart
Usa helm create para crear un chart. Examina la estructura.

## Ejercicio 2: Instalar y actualizar
Instala el chart. Actualiza values.yaml y haz upgrade.

## Ejercicio 3: Valores personalizados
Usa --set para cambiar valores en instalacion: helm install --set replicaCount=5.

## Ejercicio 4: Repositorio de charts
Agrega repositorio bitnami. Instala nginx desde bitnami/nginx.

## Ejercicio 5: Rollback
Actualiza el release. Haz rollback a la revision anterior.
