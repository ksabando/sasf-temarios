﻿# Ejercicios -” Networking y Service Mesh

## Ejercicio 1: Service ClusterIP
Crea un Deployment y exponlo como ClusterIP. Accede desde otro Pod.

## Ejercicio 2: NodePort
Cambia el Service a NodePort. Accede desde el host.

## Ejercicio 3: Ingress
Crea un Ingress para enrutar a tu servicio. Usa nginx ingress controller.

## Ejercicio 4: NetworkPolicy
Crea una NetworkPolicy que permita solo trafico desde Pods con label app: frontend.

## Ejercicio 5: mTLS con Istio (opcional)
Instala Istio. Habilita mTLS entre servicios.
