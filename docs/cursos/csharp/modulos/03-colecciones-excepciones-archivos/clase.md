## Colecciones, Excepciones y Archivos

Las colecciones permiten trabajar con grupos de objetos. Las excepciones permiten manejar errores sin romper el flujo completo del programa. Los archivos permiten persistir informacion entre ejecuciones.

### Colecciones comunes

| Coleccion | Uso |
|-----------|-----|
| `List<T>` | Lista ordenada de elementos |
| `Dictionary<TKey,TValue>` | Busqueda por clave |
| `HashSet<T>` | Elementos unicos |

## Errores esperados

Validar entradas del usuario y lanzar excepciones propias cuando una regla de negocio no se cumple mejora la claridad del codigo.
