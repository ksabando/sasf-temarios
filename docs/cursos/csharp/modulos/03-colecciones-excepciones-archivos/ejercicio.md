## Ejercicio: Persistencia JSON

Extiende el inventario para:

1. Guardar productos en un archivo JSON.
2. Cargar productos al iniciar.
3. Manejar archivo inexistente.
4. Mostrar mensajes claros ante errores.

## Criterios

- Usar `System.Text.Json`.
- Usar `try/catch` solo donde se pueda responder al error.
- No perder datos al guardar.
