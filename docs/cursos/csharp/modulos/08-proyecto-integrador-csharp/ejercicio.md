## Proyecto Integrador

Entrega una app que permita CRUD de productos, persistencia JSON, busqueda con LINQ, alertas de stock y pruebas unitarias.

## Criterios

- Separacion por responsabilidades.
- Manejo robusto de errores.
- Pruebas para reglas centrales.
- README con instrucciones de ejecucion.
