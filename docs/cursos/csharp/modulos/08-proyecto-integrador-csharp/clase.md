## Proyecto Integrador C#

El cierre del curso consolida sintaxis, POO, colecciones, LINQ, asincronia y pruebas en una aplicacion de consola mantenible.

### Estructura sugerida

| Carpeta | Contenido |
|---------|-----------|
| Domain | Entidades y reglas |
| Application | Casos de uso |
| Infrastructure | Archivos JSON |
| ConsoleUI | Menu e interaccion |
| Tests | Pruebas unitarias |

## Resumen

El objetivo no es una consola grande, sino una base limpia para evolucionar a API.
