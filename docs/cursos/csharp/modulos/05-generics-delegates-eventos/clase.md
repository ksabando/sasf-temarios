## Generics, Delegates y Eventos

Los generics permiten crear codigo reutilizable sin perder tipos. Los delegates representan funciones como valores. Los eventos permiten notificar cambios sin acoplar directamente al emisor con los receptores.

| Concepto | Uso |
|----------|-----|
| `List<T>` | Coleccion tipada reutilizable |
| `Func<T>` | Funcion que retorna valor |
| `Action<T>` | Funcion sin retorno |
| `event` | Notificacion controlada |

## Resumen

- Usar generics para evitar duplicacion.
- Usar delegates para parametrizar comportamiento.
- Usar eventos para comunicar cambios del dominio.
