## Programacion Orientada a Objetos

La POO permite representar conceptos del negocio como objetos con estado y comportamiento. En C#, una clase define la estructura y cada objeto es una instancia concreta.

### Pilares

| Pilar | Descripcion |
|-------|-------------|
| Encapsulamiento | Proteger estado interno y exponer operaciones controladas |
| Herencia | Reutilizar comportamiento desde una clase base |
| Polimorfismo | Usar diferentes implementaciones mediante una abstraccion comun |
| Abstraccion | Ocultar detalles innecesarios |

## Recomendacion practica

Preferir composicion e interfaces cuando el modelo puede variar. Usar herencia solo cuando exista una relacion clara de tipo "es un".
