## Ejercicio: Modelo de Inventario

Crea las siguientes clases:

1. `Producto` con nombre, precio y stock.
2. `Categoria` con nombre y descripcion.
3. `IProductoRepository` con operaciones de agregar, listar y buscar.
4. Una implementacion en memoria.

## Criterios

- Encapsular validaciones dentro de la clase.
- Usar propiedades publicas y campos privados cuando aplique.
- Usar una interfaz para desacoplar el almacenamiento.
