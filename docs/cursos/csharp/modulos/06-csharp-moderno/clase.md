## Nullable, Records y Pattern Matching

C# moderno reduce errores comunes y mejora la expresividad. Nullable reference types ayudan a detectar posibles `null`. Los records modelan datos inmutables. Pattern matching simplifica decisiones por forma o tipo.

| Feature | Beneficio |
|---------|-----------|
| Nullable | Menos errores por referencia nula |
| Record | Modelos de datos concisos |
| `init` | Inicializacion segura |
| Pattern matching | Condiciones mas expresivas |

## Resumen

Aplicar estas features cuando mejoran claridad, no solo por novedad.
