## Ejercicio: Refactor Moderno

Refactoriza el modelo de inventario:

1. Activa nullable reference types.
2. Convierte DTOs simples a records.
3. Usa pattern matching para clasificar stock.
4. Evita setters innecesarios.

## Criterios

- Sin warnings de null relevantes.
- Records para datos transportados.
- Reglas legibles.
