## Proyecto Final: Inventario de Consola

Completa una app que permita:

1. Crear productos.
2. Listar productos.
3. Buscar por nombre.
4. Filtrar por stock bajo.
5. Guardar y cargar datos desde JSON.

## Criterios

- Usar LINQ para busquedas y filtros.
- Usar metodos asincronos para lectura/escritura de archivo.
- Separar modelo, repositorio y menu de consola.
