## LINQ y async/await

LINQ permite consultar colecciones con una sintaxis expresiva. `async` y `await` permiten ejecutar operaciones de espera sin bloquear el hilo principal.

### Operadores LINQ frecuentes

| Operador | Uso |
|----------|-----|
| `Where` | Filtrar |
| `Select` | Proyectar |
| `OrderBy` | Ordenar |
| `GroupBy` | Agrupar |
| `FirstOrDefault` | Obtener un elemento o valor por defecto |

## Async

Usar asincronia en operaciones de I/O: archivos, base de datos, red o APIs. No usar `async` solo para calculos simples en memoria.
