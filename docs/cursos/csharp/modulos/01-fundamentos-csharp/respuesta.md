## Solucion esperada

- El programa solicita producto, precio y cantidad.
- Valida entradas numericas.
- Calcula `total = precio * cantidad`.
- Informa stock bajo si `cantidad < 5`.
- Permite cargar varios productos hasta que el usuario decida salir.
