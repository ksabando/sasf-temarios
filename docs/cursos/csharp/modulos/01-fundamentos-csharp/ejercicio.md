## Ejercicio: Calculadora de Inventario

Crea una app de consola que permita:

1. Registrar nombre de producto.
2. Registrar precio unitario.
3. Registrar cantidad.
4. Calcular total.
5. Mostrar si el stock es bajo cuando la cantidad sea menor a 5.

## Criterios

- Validar que precio y cantidad sean mayores a cero.
- Usar `if` para la alerta de stock.
- Usar al menos un ciclo para registrar varios productos.
