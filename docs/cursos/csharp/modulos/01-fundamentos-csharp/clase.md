## Fundamentos de C#

C# es un lenguaje fuertemente tipado, orientado a objetos y usado principalmente dentro del ecosistema .NET. Un programa basico se organiza en clases y metodos; el punto de entrada tradicional de una aplicacion de consola es `Main`.

### Conceptos base

| Concepto | Ejemplo | Uso |
|----------|---------|-----|
| Variable | `int cantidad = 10;` | Guardar datos modificables |
| Constante | `const decimal IVA = 0.1m;` | Guardar datos fijos |
| Condicion | `if (cantidad > 0)` | Decidir flujo |
| Ciclo | `foreach (var item in items)` | Repetir acciones |

### Flujo recomendado

1. Leer datos.
2. Validar datos.
3. Procesar reglas.
4. Mostrar resultado.

## Resumen

- C# obliga a declarar tipos y esto reduce errores tempranos.
- Las estructuras de control permiten expresar reglas de negocio simples.
- La consola es suficiente para practicar logica antes de pasar a APIs o web.
