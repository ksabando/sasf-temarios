## Ejercicio: Tests de Inventario

Agrega pruebas para:

1. Producto no permite precio negativo.
2. Stock no puede quedar negativo.
3. Busqueda por nombre ignora mayusculas.
4. Stock bajo se detecta correctamente.

## Criterios

- Usar xUnit.
- Usar nombres descriptivos.
- Incluir al menos una prueba parametrizada.
